# Smart Healthcare System

## About the Project
Smart Healthcare System is a web-based project developed to support healthcare-related services through a simple and user-friendly interface.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP


## Features
- User-friendly web interface
- Healthcare-related information and services
- Database integration
- Dynamic functionality using PHP

## Requirements
- XAMPP
- Web browser


## How to Run the Project
1. Install and start Apache and MySQL in XAMPP.
2. Place the project folder inside the `htdocs` directory.
3. Import the project database into phpMyAdmin, if required.
4. Open your browser and visit `http://localhost/Smart-Healthcare-System/`.

## Project Purpose
This project was developed as a college project to practice web development, server-side programming, and database integration.
